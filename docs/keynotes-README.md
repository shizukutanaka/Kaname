# Kaname Keynote 文書群

## 役割分担

| ファイル | 用途 | 対象読者 |
|---|---|---|
| `vision-keynote.md` | 北極星の核となる短い宣言 | 全員 (新規参加者の必読) |
| `launch-keynote-2026.md` | WWDC 風 30 分発表台本 | リリース時の脚本担当 |

## 使い分け

- **設計判断に迷ったとき** → `vision-keynote.md` を読む
- **リリースイベント準備** → `launch-keynote-2026.md` を読む
- **新規参加者へのオンボーディング** → 両方読む

## Apple 流の原則

> 製品を作る前に、発表の日に話す言葉を書く。そこから逆算する。

`vision-keynote.md` を更新する権限は `@kaname-app/lead` のみ。
このドキュメントは Kaname のすべての設計判断の基準点。
