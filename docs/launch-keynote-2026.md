## ACT I — THE PROBLEM (2:00 - 7:00)

**スピーカー登壇 (DRI):**

「皆さん、おはようございます。

2026 年現在、ビジネスメール詐欺 (BEC) は世界で年間 **510 億ドル** の被害を出しています。一方、AI を活用したメールクライアントは便利だけれど、新たな攻撃面を生み出しています」

**スライド: 4 つの脅威**

1. **AI 駆動 BEC** — IBM の研究で 95% コスト削減、5 分で生成可能
2. **プロンプト注入** — Superhuman で 1 通のメールが受信箱全体を漏洩
3. **DLP バイパス** — Microsoft Copilot で機密メールが要約された
4. **量子コンピューター (HNDL)** — 今暗号化したメールが将来解読される

「これらは独立した問題ではない。AI 時代のメールが抱える**構造的な問題**です。

そして従来のメールクライアントは、**この時代を想定していない**設計です」

**画面:** Outlook、Gmail、Superhuman、Proton Mail のアイコンが並ぶ。
赤い ✗ がそれぞれにつく。

「だから私たちは、**ゼロから作り直しました**」

「セキュリティは、ランタイムでチェックするものではない。
**コンパイラが証明する**ものです」

**デモ:** VS Code で Rust コードを表示

```rust

//              ^^^^^^^^^^^ コンパイルエラー!
```

「Superhuman で起きた CVE は、Kaname では型システムが防ぎます。
ランタイムチェックではない。実行不可能です」

「メールを処理する速さは、知性に直結します」

**デモ:** ⌘K でコマンドパレットを開く → スワイプジェスチャーでアーカイブ → Cmd+Z で取り消し

「The Screener、Reply Later、Spotlight 検索、自然言語クエリ。
HEY と Superhuman の最高の体験を、ローカルファーストで」

### 🔒 Privacy — データはデバイスを離れない

「全 AI 推論は、ローカル。
全メールデータは、SQLCipher 暗号化。
全件名は、MLS で暗号化」

### Scene 2: AI 要約のセキュリティ証明

「では、安全なメールを AI で要約してみましょう」

**画面:** 田中花子さんからの会議案内メールを選択

**画面:** メール上部のバナー:
> ✨ AI で要約 — このメール 1 通のみ分析 🔒 安全

「クリックすると...」

**画面:** バナーが展開

「これは飾りではありません。**型システムでコンパイル時に保証されています**。

### Scene 3: Smart Reply (3 候補)

**画面:** 「返信案を生成」ボタン → 3 つのカプセル形状ボタンが現れる:

「アーカイブしました」

**画面:** スワイプアニメーションでメールがリストから消える → Toast 表示「アーカイブしました (⌘Z)」

**画面:** メールが戻る

「macOS の全アプリと同じ Cmd+Z 契約。**50 件まで遡れます**」

### Scene 5: Continuity (One More Thing)

**スピーカー:**

「最後に、もう 1 つお見せします」

**画面:** iPhone を取り出す。Kaname iOS 版が表示される。スクロール途中のメール。

**画面:** Mac の前に座る → Mac の Dock に Kaname アイコンが現れる → クリック

**画面:** Mac の Kaname が、iPhone と**同じスクロール位置**で開く

「Handoff です。iPhone で読み始めたメールを、Mac で続ける。
**Continuity** は、Apple の OS が提供する素晴らしい機能。
そして Kaname は、それを**正しく**実装しています」

「セキュリティ?」

## 付録 — 緊急対応

### Q&A 想定問答

**Q: Phi-4-mini は何 GB のメモリを使う?**
A: 量子化版 Q4_K_M で約 2.5GB。M1 以降の Mac で動作。

**Q: なぜ Rust?**
A: メモリ安全性、型レベル保証、Tauri との統合性、リリースバイナリの小ささ。

**Q: ライセンスは AGPL-3.0。商用利用は?**
A: 完全に可能。AGPL は使用ではなく**サーバー改造時の再配布**を制限。
   v0.5 で商用ライセンスも提供予定 (デュアルライセンス)。

**Q: 量子コンピューターはいつ脅威になる?**
A: NIST は 2030 年代に CRYPTOGRAPHIC RELEVANT QUANTUM COMPUTER (CRQC) を予想。
   Kaname は **HNDL (Harvest Now Decrypt Later)** 攻撃を今から防ぐ。

**Q: Apple Intelligence と競合しない?**
A: Apple Intelligence は便利。しかし **DLP ラベルを尊重しない**ため、
   機密メールに使うのは危険。Kaname はそのギャップを埋める。

### デモ機材セットアップ

- **メイン Mac**: M3 Pro, macOS 26 Tahoe
- **iPhone デモ用**: iPhone 17 Pro, iOS 26
- **エコシステムデモ**: iPad Air M4
- **画面共有**: Apple TV (4K, AirPlay)
- **バックアップ Mac**: M2 Pro
- **モックサーバー**: kaname-mockserver localhost:8080

### 緊急時のトラブル対応

- BEC メールが赤色にならない → mockserver の fixture-002 を再起動
- Handoff が動かない → Bluetooth + Wi-Fi 両方有効化を確認
- AI 要約が遅い → Phi-4-mini モデルがロード済みか確認 (起動時 4 秒)
- Liquid Glass がぼやけない → macOS 25 以下の可能性、Sequoia 必須
