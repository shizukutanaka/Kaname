# BEC スコアリング — 言語非依存仕様

バージョン: 1.0 | 作成日: 2026-05-26

---

## 1. 概要

BEC (Business Email Compromise) スコアリングは 7 つの信号を組み合わせて
0.0〜1.0 のリスクスコアを計算する。

---

## 2. スコア閾値

| スコア | カテゴリ | UI 表現 |
|---|---|---|
| 0.0 以上 0.3 未満 | Safe | 何も表示しない |
| 0.3 以上 0.5 未満 | Advisory | 黄色の注意バナー |
| 0.5 以上 0.7 未満 | Suspicious | オレンジの警告バナー |
| 0.7 以上 1.0 以下 | Dangerous | 赤い危険バナー + 送信ブロック推奨 |

---

## 3. 7 つの信号

### 信号 1: ドメインタイポスクワット (Levenshtein 距離)
- 既知の正規ドメインからの編集距離が 1〜3 の場合
- 完全一致は除く (正規ドメインと一致する場合は 0 点)
- スコア加算: +0.40

### 信号 2: 緊急性マーカー
- 「至急」「緊急」「本日中」「urgent」「immediately」等
- スコア加算: +0.15 (マーカーごと、最大 0.30)

### 信号 3: 振込パターン
- 「振込」「口座変更」「wire transfer」「payment change」等
- スコア加算: +0.30

### 信号 4: 送信時刻異常
- 深夜 22:00〜翌 5:00 の送信
- 土日祝日の緊急依頼
- スコア加算: +0.15

### 信号 5: QR コードフィッシング
- 添付画像内の QR コードから疑わしい URL が検出された場合
- スコア加算: +0.25

### 信号 6: VEC パターン
- 既知取引先ドメインの Levenshtein 距離 1 偽装
- スコア加算: +0.45

### 信号 7: メール爆撃
- 同一送信者から短時間に大量メール
- スコア加算: +0.20

### 最終スコア計算
全信号の合算を 1.0 で上限クリップする:
```
final_score = min(sum(signal_scores), 1.0)
```

---

## 4. 不変条件

- スコアは常に 0.0 以上 1.0 以下
- 同一入力からの計算は常に同じスコアを返す (決定論的)
- 悪い信号を追加するとスコアは低下しない (単調増加)
- 空のメールはスコア 0.0
