# Out-of-Band Verification — 言語非依存仕様

バージョン: 1.0 | 作成日: 2026-05-26

---

## 1. 概要

OOBV は Deepfake 音声/動画詐欺と VEC (Vendor Email Compromise) への対抗策。
メール経路に加えて **別経路 (電話/対面) で双方向検証** する儀式。

---

## 2. 検証フロー

```
1. Kaname がメール内の金融キーワード + 緊急性を検出
2. 6 ワードのフレーズを生成 (50 ワードの安全な部分集合から)
3. ランダムに 1〜6 の「チャレンジ番号」を選択
4. UI に表示: 「3 番目のワードを電話で確認してください」
5. ユーザーが送信者に電話して確認
6. 送信者は同じ画面を見て 3 番目を読み上げる
7. 一致 → Verified / 不一致 → Blocked
```

---

## 3. セキュリティ特性

### なぜチャレンジ番号方式か

攻撃者が Deepfake 音声でフレーズを傍受しても:
- チャレンジ番号 N が動的に変わるため、毎回別の単語が必要
- 1 回の攻撃で 6 ワード全部を聞き出す方法がない
- 5 分の期限内に繰り返し試行することも困難

### 安全なワードリスト要件

- 電話越しで聞き間違いにくい単語 (短い、明瞭な発音)
- 日本語話者にも発音しやすい英語単語
- 意味から内容を類推されにくい単語

---

## 4. 推奨トリガー条件

| 条件 | スコア加算 |
|---|---|
| 金融キーワード (振込/wire transfer 等) | +1 |
| 緊急性キーワード (至急/urgent 等) | +1 |
| 合計 2 以上 | Strong 推奨 |
| 合計 1 | Optional 表示 |
| 合計 0 | 表示なし |

---

## 5. 監査ログ要件

- 検証イベント (成功/失敗/タイムアウト) を記録
- フレーズ本文は記録しない (シークレット)
- タイムスタンプ、メール ID、送信者、結果を記録
- 改ざん防止 (ハッシュチェーン推奨)
