## 解体 (3 フェーズ)

### Phase 1 — 敵対的サンプル生成器 (D2 Phase 4 後)

- 自組織の送信者プロファイル (SenderStyleProfile) を入力に、
  ローカル LLM (D2 Phase 1-3 で稼働する Phi-4-mini) に
  「このプロファイルの文体で、以下の件名/本文をその人らしく書け」と
  生成させる敵対的メール生成器を `kaname-ssa` または `kaname-tests` に追加。
- 生成条件を変化させる: temperature 複数値 / プロンプト指示
  (「丁寧さを少し上げろ」「文体特徴を半分だけ真似ろ」) で
  検知回避の難易度グラデーションを作る。
- **この生成器はテスト/校正用途のみ** — 本番パイプラインには接続しない
  (生成した敵対サンプルが製品に流れ込まないよう、
  `kaname-tests` または dev-dependency 側に置く)。

### Phase 2 — 検出率測定ハーネス

- 生成した敵対サンプル群に対し、現行 `style_distance` を計算し
  「閾値 θ での検出率 / 誤検知率」の ROC 相当を取る。
  - 正例: 生成されたなりすましメール (検出すべき)
  - 負例: 実送信者の正常メール (誤検知してはいけない)
- 評価指標: Medium 警告の検出率 (≥80% が目標案)、
  誤検知率 (正常メールで `distance >= 0.60` となる率 ≤5% が目標案)。
  これらの数値目標自体も Phase 2 の出力で確定させる。

### Phase 3 — 閾値校正 + 回帰ガード

- 測定結果に基づき `warning_level` の 0.60/0.75 を校正
  (例: LLM なりすましが distance 0.5-0.7 に集中するなら Medium を 0.55 に
  下げる等 — 実値で決める)。
- 校正は**定数変更ではなくデータ駆動**: `docs/ssa-calibration.md` に
  測定手順と結果を記録し、閾値の変更には再測定を要求する
  (「経験値を書き換えた」状態に戻らないための手続き)。
- kaname-tests に回帰テスト: 既知の敵対サンプル固定セットが
  校正済み閾値で検出されることを CI (D63 復活後) で確認。

## リスク

- LLM が「その人らしさ」を十分に模倣できない場合、校正された閾値は
  実際の敵対者に対して過剰に緩い可能性 — arxiv 2603.29454 の知見は
  「含めなければ回避される」であり、含めても防御を保証するものではない。
  校正後も SSA は「1シグナル」として BEC 判定に寄与する位置付けを維持
  (kaname-bec の10シグナルファミリーの一部)。
- 敵対的サンプル生成器自体が二面的な用途を持つ — コード・ドキュメントとも
  「校正用途のみ」「本番接続しない」ことを明記する (本書で明記済み)。

## Phase 2 部分実施の実測結果 (2026-09-20)

モデル不要の決定論的測定として、`kaname-ssa` に `calibration_tests`
モジュールを追加した。「被害者プロファイルを完全に知る攻撃者が各軸を
最大乖離させる」31 軸サブセットを列挙し、検出面を回帰ガード化。

### 実測された検出面 (重み: 時刻 .25 / formality .25 / 文長 .20 / 長さ .15 / 読点 .15)

| 攻撃者の乖離 | 最大距離 | 警告 |
|---|---|---|
| 1 軸のみ最大乖離 | 0.25 | **なし** (Low にも届かない) |
| 2 軸最大乖離 | ~0.45 | Low まで (Medium 不可) |
| 最強 3 軸 (時刻+formality+文長) | ~0.65 | Medium |
| 全 5 軸 | 1.0 | High |

### 発見

- **単一軸の攻撃は完全に不可視**: 「文体を完璧に真似たが深夜送信」
  のようななりすましは Low にも届かない (0.25 < 0.40)
- **`paragraphs` / `sentences_per_paragraph` / `signature_lines` は
  デッド次元**: `extract` は行うが `style_distance` の重み計算に
  一切寄与しない。プロファイルが保持する 8 次元のうち 3 次元は
  判定に使われていない — 攻撃者はこれらを自由に変えられる
- 誤検知面は健全: 正当なばらつき (±20% + 1 時間ずれ) で警告なし

### Phase 3 への示唆

閾値校正の前に「何を検出したいか」を再確認する価値がある:
Medium 閾値を下げるより、デッド次元 (段落構造・署名行数) を
重み計算に投入する方が検出面の形を大きく変えられる可能性が高い。
