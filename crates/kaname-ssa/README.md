# kaname-ssa

> Sender Style Authentication — 送信者文体認証

2026年の最大課題「AI が生成した完璧文法の偽メール」を、**文体の指紋**で検出する。

## 主要機能

- 30+ 通の過去メールから送信者の文体指紋を構築
- 送信時刻分布、フォーマリティ、文長リズム、句読点密度を計測
- スタイル距離 (0.0〜1.0) で乖離を定量化
- 閾値 0.60 以上で警告、0.75 以上で強警告
- プライバシー保護: コンテンツは一切保存しない (数値ベクトルのみ)
